# Kenney Input Prompts

This directory contains the complete Kenney Input Prompts 1.5A asset pack,
staged as placeholder UI art for the prototype.

The original pack layout is preserved by device family. Use the `Default`
folders for raster prompts, or the `Vector` folders when a scalable source is
preferable. The pack includes keyboard, touch, generic controller, and
platform-specific prompt variants.
