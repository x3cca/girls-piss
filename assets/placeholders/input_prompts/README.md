# Kenney Input Prompts

This directory contains the complete Kenney Input Prompts 1.5A asset pack,
staged as placeholder UI art for the prototype.

The original pack layout is preserved by device family. Use the `Default`
folders for raster prompts, or the `Vector` folders when a scalable source is
preferable. The pack includes keyboard, touch, generic controller, and
platform-specific prompt variants.

The pack is released under CC0. See [License.txt](License.txt) for the
original license and attribution details.

The root-level `aim.png` and `piss.png` files are project-specific temporary
action labels placed beside the Kenney icons. `scenes/input_prompt.tscn` shows
aim and stream instructions as separate stacked rows, reusing the same prompt
node when the input source changes. These labels are intentionally placeholders
until more descriptive instructional artwork is available.
