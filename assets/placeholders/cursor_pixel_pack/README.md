# Kenney Cursor Pixel Pack

This directory contains Kenney's Cursor Pixel Pack 1.0, staged as placeholder
cursor art for the prototype.

Use the individual 16×16 images in `Tiles/` for direct swaps, or use
`Tilemap/tilemap.png` and the layout details in `Tilesheet.txt` when a packed
sheet is more convenient.
