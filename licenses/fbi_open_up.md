# FBI Open Up meme cues

- Original video: [FBI Open Up - Sound Effect (HD)](https://www.youtube.com/watch?v=QQR7t712Mhg)
- Creator: Gaming Sound FX
- Source sections: `00:00.34–00:01.20` for the voice and `00:01.405–00:02.24` for all three knocks

The repository assets `assets/audio/fbi_open_up_voice.ogg` and
`assets/audio/fbi_door_smash.ogg` are trimmed OGG excerpts from the source
video. The second excerpt contains the three knocks used by the DoorBang
animation. The source page does not state a permissive reuse license; these
excerpts should be treated as copyrighted and cleared before external
redistribution.
