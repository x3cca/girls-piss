# FBI Open Up meme cues

- Original video: [FBI Open Up - Sound Effect (HD)](https://www.youtube.com/watch?v=QQR7t712Mhg)
- Creator: Gaming Sound FX
- Source sections: the complete `00:00.00–00:03.007` source audio is used for
  `fbi_open_up_voice.ogg`; `00:01.405–00:02.24` is also retained as the
  separate three-knock excerpt

The repository asset `assets/audio/fbi_open_up_voice.ogg` is the complete
source audio transcoded to OGG. `assets/audio/fbi_door_smash.ogg` is a trimmed
OGG excerpt containing the three knocks used by the DoorBang animation. The
source page does not state a permissive reuse license; these assets should be
treated as copyrighted and cleared before external redistribution.
